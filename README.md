# Diwali Sales Data Analysis

# Project Overview
This project focuses on analyzing Diwali sales data to gain meaningful business insights. The dataset includes customer demographics, product categories, purchase amounts, and more.

The goal of this project is to perform **Exploratory Data Analysis (EDA)** and identify trends that can help businesses improve sales strategies.

## Objectives
- Understand customer purchasing behavior
- Identify top-selling product categories
- Analyze sales based on gender, age, and marital status
- Find high revenue-generating states
- Help businesses target the right audience


## Tools & Technologies Used
- Python (Pandas, NumPy)
- Matplotlib, Seaborn
- VS code
- Microsoft Excel
- Power BI

## Dataset
- The dataset used is **Diwali Sales Data**
- Contains customer details such as:
  - Gender
  - Age Group
  - State
  - Occupation
  - Product Category
  - Amount

## Key Analysis Performed
- Data Cleaning (handling null values, removing unnecessary columns)
- Gender-wise analysis
- Age group vs purchase analysis
- State-wise sales analysis
- Product category performance

## Key Insights
- Most buyers are **female customers**
- Age group **26–35 years** contributes the most to sales
- Top purchasing states generate higher revenue
- Certain product categories dominate sales

## Visualizations
- Gender distribution (Count Plot)
- Age Group vs Gender sales (Bar Chart)
- State-wise top 10 sales (Bar Chart)
- Product Category-wise top 10 sales (Bar Chart)

## Power BI Dashboard
Along with Python EDA, an interactive Power BI dashboard (`data_analyst_project_powerbi.pbix`) was created to visualize:
- Total sales by state and zone
- Gender and age-group wise purchase trends
- Top-selling product categories
- Sales distribution by occupation


## How to Run the Project
1. Download or clone the repository
2. Open the `.ipynb` file in Jupyter Notebook / VS Code
3. Make sure `Diwali_Sales_Data_DA.xlsx` is in the same folder as the notebook
4. Install required libraries:
   pip install pandas numpy matplotlib seaborn openpyxl
5. Run all cells in order (Kernel → Restart & Run All)
6. Open `data_analyst_project_powerbi.pbix` in Power BI Desktop to view the dashboard
